# Outside_Weather_Sync
-Weather sync to Datacake schedule to every one hour-

All rights reserved to MycoLutions GmbH. This is a script and workflow I developed as an IoT and Sensor Systems Engineering intern. 

In order to optimize the monitoring system, I built an automated data pipeline using GitHub Actions. This repository contains the workflow and the script that was used. Outside weather
(Temperature and Humidity) are fetched from Open-Meteo API and feeding to our IoT dashboard on scheduled cron cycles.
